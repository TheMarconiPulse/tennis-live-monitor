# Tennis Live Monitor

A lightweight, rate-limit-aware Python utility to fetch and display live tennis match scores, tournament details, and set breakdowns using the LiveTennisAPI.

## Prerequisites

1. **Python 3.10+**
2. **LiveTennisAPI Key:** This script requires an active API key. You can sign up and get your API key here:  
   👉 [Register for LiveTennisAPI](https://affiliates.livetennisapi.com/r/themarconipulse)
